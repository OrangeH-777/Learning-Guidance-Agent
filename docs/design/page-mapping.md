# 页面编号与实现核对

2026-09-28，作者核对；团队原型评审尚待实际执行。编号采用第二循环文档，第一循环的编号不混用。

| 原编号 | 原业务含义 | 当前入口与实现 | 验证 |
| --- | --- | --- | --- |
| P0 | 注册与登录 | `/login`，AuthView | 注册、退出、受保护入口、401回跳、网络失败 |
| P1 | 学习工作台 | `/`，DashboardView | 当前课程、模型/画像准备状态、最近任务 |
| P2 | 对话画像与确认 | `/profile`，ProfileView | 对话草稿、编辑确认、取消、版本、课程切换 |
| P3 | 生成学习资源 | 工作台“创建学习资源”区域 | 课程、主题、类型、画像版本、知识就绪门禁 |
| P4 | 生成进度与失败处理 | 工作台“最近任务”区域 | 状态轮询、刷新、失败原因、原配置重试 |
| P5 | 资源详情 | `/resources/:id`，ResourceView | 三类结构、来源、AI提示、原配置、返回历史 |
| P6 | 历史记录 | `/history`，HistoryView | 筛选、稳定分页、空态、错误、返回后恢复条件 |
| 新增M1 | 个人模型设置 | `/models`，ModelsView | 四种协议、保存/停用、密钥状态、主动连通测试 |

当前将P1/P3/P4整合到工作台，保留各自业务含义；课程选择出现在工作台、画像和历史中。登记此映射用于评审，不虚构原团队的评审结果。

核对时发现P6返回路径丢失筛选/页码，已改为由URL保存查询条件，资源链接携带仅允许指向`/history`的返回位置。前后端请求不因浏览资源再发起生成。资源切换时取消旧请求，防止迟到来源覆盖新页面。

作者浏览器检查见`frontend/e2e/learning.spec.ts`和`failure-states.spec.ts`：Chrome/Edge、390px窄屏、键盘聚焦、加载/空态/失败/会话失效、退出断网、课程画像草稿隔离、返回历史。原型评审还应明确工作台区域合并，以及当前“注册后直接登录进入工作台”相对原文“注册后返回登录页”的交互差异；未将其记录为已获团队批准。
