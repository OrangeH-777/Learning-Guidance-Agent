# 用户手册

## 账号与课程

注册账号使用4—20位字母、数字、下划线；大小写不区分。密码8—64个Unicode字符，含字母与数字。退出会撤销服务端当前会话；网络错误时页面会明确显示“服务端退出尚未确认”，请恢复网络后重试。

工作台选择课程。每门课程的画像、草稿、任务与来源独立；停用课程不能创建新任务，旧资源仍可按原来源读取。当前仅登记数据结构，新增课程需维护对应 course.yaml 和资料。

## 个人模型

模型ID和API Key由你填写模型服务商提供的值，与本站登录用户名、密码无关。新用户的模型字段为空，未保存的登录信息不会生成模型配置。“模型设置”使用独立字段标识、关闭自动填充并采用可显隐密钥遮罩，避免被当作登录表单。

在“模型设置”选择接口协议，输入版本根地址、模型ID和密钥，保存后点击“连接测试”。该操作会实际调用所选服务，可能收费。未保存或未测试通过时不能生成。Base URL 默认公网HTTPS，内网/本地服务需部署方明确放行。

修改尚未保存时不能测试旧设置，页面会提示先保存；保存后以服务端返回的规范地址回显。连接测试失败后须重新验证成功才能创建新生成任务。连接测试和画像提取都受单次模型总时限约束，迟到结果不会作为成功返回。

页面只显示密钥是否已保存，刷新和保存后API Key输入框为空，留空保存时保留已有密钥。下方“我的配置记录”分页展示你本人历次保存的协议、模型ID、地址、时间及密钥保存状态，不回传明文密钥。已有记录仍按用户ID严格隔离；物理分表含义待用户确认，当前没有实施动态建表迁移。若之前因自动填充误保存了登录信息，请重新填写正确模型配置，系统不会擅自删除你的历史记录。移除设置会停用当前设置；已受理任务保留原版本运行上下文。模型提供商可能接收到必要的画像字段、所选课程片段与候选资源；系统不向模型发送账号、登录密码、会话令牌或模型API Key正文。

## 学习画像

选择课程后，可以手动填写基础、目标与偏好，也可以展开对话入口让模型整理。缺项时追问；冲突时请手动修正。模型提取只是草稿，不等于你已确认。

个人模型通过连接测试后，可以点击“根据历史生成并保存”。模型会参考你在当前课程已保存的画像、最近 20 份学习资源的需求主题、类型和标题，以及最近 8 条画像对话中的个人陈述，一次填入并保存三个字段。记录不足以判断某项时，模型会被要求标明待确认之处。首次使用且没有历史时，可以先在对话中描述自己的学习情况，再点击生成。生成后仍可编辑字段，后续新建任务使用最新保存的画像。

每个字段最多 500 字符，每条对话最多 1000 字符。手动修改后点击“确认并保存画像”，相同内容沿用原版本。“取消修改”会重新读取已保存的画像。多个页面修改同一版本时，后提交者会看到冲突提示，可点击“取消修改”读取最新版本。

刷新或切换课程后，表单先显示该课程已确认画像。点击“恢复对话草稿到表单”可取回服务端保存的对话草稿，检查后再确认保存；恢复本身不会增加画像版本。尚未保存的手动输入不属于服务端草稿。

## 生成、失败与重试

在工作台选择课程和已校对的教材章节，填写学习需求（最多 100 字符），再选择概念讲解、巩固练习或文本思维导图。开始前请保存本课程的画像，并在个人模型设置中通过连接测试。所选章节正文会随学习需求一起发送给模型。

点击“开始生成”，右侧“生成过程”会显示本次任务的实际阶段，包括等待、规划、生成、核验和整理。手机上进度显示在表单下方。资源保存后会自动打开结果页。返回工作台后，展开“最近生成记录”可查看近期结果和失败任务，也可从“学习历史”浏览全部已保存资源。

失败原因显示在进度区域。“沿用原配置重试”使用原任务的画像、模型和章节快照创建新任务。若想使用新画像或其他章节，请从生成表单发起新任务。

断网查询仅代表连接失败，不会把服务端任务显示为已失败。服务重启后未完成任务会标 INTERRUPTED，可在恢复后手动重试。

## 阅读与历史

讲解按目标、先修、要点、实例和小结展示；练习可展开答案解析；导图展示树形文本。所有成功资源显示“由AI生成，仅供参考”，自动核验不等于人工复核或事实绝对正确。

资源详情可展开原配置及来源片段。历史按课程、主题、类型筛选，每页10条；正文、画像版本、模型和知识版本为生成时快照，不随后续设置变化。首期没有公开分享、资源删除、导出和个人教材上传入口。

历史筛选条件和页码保存在页面地址中，从历史进入资源后点击“返回学习历史”会恢复原条件；刷新也会保留。资源正文不会因返回历史而重新生成。

## 常见情况

| 提示 | 处理 |
| --- | --- |
| 知识索引待准备 / EMBEDDING_NOT_CONFIGURED | 联系部署方填写嵌入配置、复核资料并建立索引 |
| MODEL_AUTH / MODEL_NOT_FOUND | 核对个人模型密钥、地址和模型ID，再测试连接 |
| VERSION_CONFLICT | 重新读取设置或画像，检查后再次确认 |
| PROMPT_VERSION_UNAVAILABLE | 服务已升级，旧提示词版本不可用；从工作台创建新任务 |
| BUSY | 等待本人或其他活动任务结束；不要连续重复提交 |
| CONTENT_REJECTED / NO_KNOWLEDGE | 缩小主题或补充可信课程资料，不把失败当作已通过内容 |
| TASK_TIMEOUT / INTERRUPTED | 查看原任务，服务恢复后按需手动重试 |
| DATABASE_UNAVAILABLE / NOT_READY | 联系部署方检查数据库、迁移和单调度进程 |

课程来源和自动核验存在限制时以页面提示与测试报告为准，不使用测试替身生成的固定样例冒充真实模型效果。

## 管理员公共教材入口

管理员登录后可通过导航中的“公共教材管理”上传 Markdown、文字版PDF和Word `.docx`，预览校对、保存为公共教材，再手动建立索引。单文件最多10 MB，扫描件先OCR、旧版`.doc`先转换。账号初始化、来源填写和使用步骤见[管理员教材手册](public-materials.md)。普通用户没有此权限；个人私有上传仍留后续。
