# 管理员公共教材管理

适用于本次确认的本地部署。管理员上传的是所有用户共享的课程教材；个人私有上传仍属后续 S12。

## 管理员登录

当前工作区管理员用户名为 `admin`，随机密码见根目录本地 `.env` 的 `ADMIN_PASSWORD`。按 README 启动前后端，用普通登录页面登录，导航中会出现“公共教材管理”。普通用户既没有管理入口，也不能直接调用管理接口。

新环境先在 `.env` 填写 `ADMIN_USERNAME` 和 `ADMIN_PASSWORD`，执行 `uv run --locked alembic upgrade head`，再执行 `uv run --locked python -m scripts.bootstrap_admin`。数据库仅保存 Argon2id 密码哈希；`.env` 是本地秘密文件，不提交到 Git。初始化仅创建新账号，重复执行不改密码、不把已有普通用户升级为管理员。修改 `.env` 后需重启后端以更新保留账号名；这不会重置已有账号密码。

## 上传、校对与保存

1. 选择已导入的课程。页面顶部提供“选择 / 上传 → 校对 / 保存 → 建立索引”步骤定位，所选课程保留在网址中，刷新后继续使用该课程。当前实际课程为数据结构；添加其他课程仍需先建立课程 YAML 并执行 `scripts.import_courses`。
2. 选择教材文件。支持 UTF-8 `.md`、有文字层的 `.pdf`、Word `.docx`，单文件不超过10 MB，提取正文最多50万字符。PDF最多500页，大书建议按章节拆分。
3. 提取成功后页面平滑滚动到校对区，键盘焦点同步移到区块标题；系统设置为减少动态效果时直接定位。检查提取正文，可直接编辑纠正。PDF可能丢失文字顺序、表格或公式；Word仅提取正文段落和表格文字。图片、公式、页眉页脚等请人工核对补充。扫描版PDF无文字时明确报错，先自行OCR；旧版`.doc`先另存为`.docx`。加密PDF需先解密。
4. 填写教材标题、来源HTTP(S)网址（如出版社书目页）、章节/页码、实际授权或使用依据。来源网址是引用信息，不会自动下载网页；自行编写的材料可填写其实际发布页或项目资料页，不要伪造出处。
5. 勾选已核对且可以公共使用，然后点击“确认并保存公共教材”。修改任一正文或来源字段后需要重新勾选。未确认时只能预览，尚不会成为课程知识。

保存会将正文写入 `knowledge/<course_id>/content/admin_<随机标识>.md`，自动登记 `course.yaml`、更新课程版本，并标记本次管理员确认的材料为 `approved`。上传文件名不作为磁盘保存路径；临时原文件在解析结束后清理，不提供原PDF/Word下载。

原有教材点击“查看 / 校对”后会自动定位至对应编辑区，可读取、修改和确认；列表会标出正在校对的条目。保存成功后自动定位到索引区，错误会定位至可见提示。清空正文不会让编辑区消失，但空白正文不能提交。切换课程、取消编辑或离开页面时，对未保存内容进行确认保护。更新时保留原来源ID，以新文件和新版本保存。每次保存会让该课程等待重新索引；其他课程不受影响。管理员只确认了自己实际校对的条目，不会顺带批准课程中其他未复核资料。

## 建立索引

统一嵌入配置仍在根目录 `.env`，字段与填写方法见[知识说明](../../knowledge/README.md)。网站不内置测试向量，也不会自动替你选择付费服务。上传、提取和保存不调用模型。

在“建立课程索引”中确认向配置的嵌入服务发送教材正文及可能费用，再点击“建立索引”。页面显示运行中、成功（片段数量）、失败或中断；若上次构建成功后教材又被修改，会明确提示需要重建，不能将旧结果当作当前就绪；离开页面不会取消后台任务，返回后可以刷新状态。只允许一个管理索引任务同时运行，期间暂不能保存教材。单次索引最长10分钟，关闭后端会中断；重启不会自动重复付费调用，需要检查状态后手动重试。

索引默认要求该课程全部教材已确认。仓库的六份原创数据结构示例均标为待人工复核；仅用于本地流程试验时，可以勾选“仅本地测试：允许未复核示例进入公共索引”。这会真实建立共享索引，不是只读预览，不改变材料的人工审查状态。

网站在同一嵌入配置族下自动生成每课程独立修订版本；重复建立会产生新版本，并可能再次计费。日常上传更新无需修改 `EMBEDDING_INDEX_VERSION`。如果改变嵌入服务的模型或维度，则更新该配置族值、重启后端，并为各课程重建。旧片段保留用于历史引用，不自动清理。

索引成功后，回到工作台，配置并测试个人聊天模型、确认当前课程画像，再生成资源。就绪检查成功或索引成功均不能单独证明真实模型教学质量已通过人工验收。

## 本地记录与故障处理

- 最新管理索引状态保存在忽略的 `knowledge/.admin-index-job.json`，不含教材正文和服务密钥。它只记录最新一次管理索引任务，不是完整审计历史。
- 同时打开多个页面修改同一课程时，旧版本保存会被拒绝；刷新后重新核对再保存。
- 常规数据库保存失败会恢复原课程 YAML、清理新文件。文件系统与数据库并非跨系统事务；若保存时进程被强制终止，先检查课程 YAML 和正文，再运行 `scripts.import_courses` 同步数据库并重新索引。
- 索引构建失败不会发布部分向量。若此前保存已使课程索引失效，失败后仍需重试，不能继续宣称旧索引覆盖新教材。
- 不要同时在网站和命令行编辑或索引同一课程。备份应包括数据库、课程目录及 `.env` 中的必要密钥。

文本提取实现参考 [pypdf 文档](https://pypdf.readthedocs.io/en/stable/user/extract-text.html)与 [python-docx 文档](https://python-docx.readthedocs.io/en/latest/api/document.html)。实际支持范围以本手册及测试为准。
