# 公共教材管理

1. 在“公共教材管理”选择课程，按章准备文件，每个文件一章。支持 UTF-8 Markdown、文字版 PDF 和 Word .docx，单文件最多 10 MB。
2. 上传后核对数字章号、章节名称，并填写可选简介。系统优先从文件名或正文中的“第十章”“第2章”等标题识别章号，其余默认建议下一个章号。可手动修改，再核对正文并补全来源网址、章节或页码、授权依据，确认后保存。
3. 章节目录和工作台按章号从小到大排列，同号保留目录中的相对顺序。点击“编辑 / 校对”可以调整章号、名称、简介、来源或正文。学生选择章节时可以看到该章简介。
4. 在要移除的章节旁点击“删除”，核对确认框中的课程、章号和名称。确认后本章从公共目录及工作台移除，已有学习资源保留生成时的章节快照。若另一位管理员刚更新了目录，点击“刷新目录”后重新核对。

旧教材中已按“第一章”“第2章”等独立标题划分的章节可以逐章管理。未指定章号的旧资料会优先从标题或来源章节识别章号，其余沿用目录位置作为初始章号。

学习者进入工作台，选择课程、已校对章节和资源类型，填写需求后点击“开始生成”。系统使用个人聊天模型处理所选章节全文。生成任务保留章节快照，重试和引用沿用提交时的正文。此流程无需配置嵌入服务。较长章节须适合所选模型的上下文窗口。
