# 任务与评审记录模板

用于本地任务记录或复制到团队Issue。远程仓库权限、分支保护和成员评审须在平台上实际执行，不以本文件存在代替完成。

| 字段 | 填写内容 |
| --- | --- |
| 任务编号 | plan中的Sx-xx或Cxx |
| 关联需求和测试 | R、UC、IT、TC或新增用例编号 |
| 主责/执行者/协作 | 实际姓名或角色 |
| 前置依赖 | 所需决定、接口、环境和任务 |
| 范围与完成条件 | 可检查的行为、交付物和边界 |
| 实施记录 | 文件、提交、实际开始结束时间和工时 |
| 验证证据 | 命令、环境、实际结果、报告或截图位置 |
| 未完成/阻塞 | 原因、解决条件、责任人 |
| 评审 | 实际评审人、时间、意见与关闭情况 |

- [ ] 依赖满足，未决方案已确认。
- [ ] 实现和文档一致。
- [ ] 对应测试已实际执行，敏感信息已脱敏。
- [ ] 非作者评审意见已处理。
- [ ] 已更新plan状态及证据链接。
