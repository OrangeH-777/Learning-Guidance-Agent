问题编号：REQ-001。文档声明三类资源各10条，但原表格实际为讲解10条、练习11条、导图9条。用户已确认仅将执行集DS13调整为二叉树文本导图。`tests/fixtures/acceptance_execution.json`记录修订依据和原编号，现为各10条；原始Word与baseline JSON保持不变。复现修订集可运行 `uv run --locked python -m scripts.prepare_acceptance_execution`。该修订不代表30条真实生成已执行。
