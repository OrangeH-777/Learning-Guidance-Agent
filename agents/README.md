# 智能体模块边界

本目录目前只有模块占位，不包含可执行的生成工作流。Python 环境统一由根目录 `pyproject.toml` 和 `uv.lock` 管理，后端将直接调用本模块。

| 目录 | 后续职责 |
| --- | --- |
| `workflows/` | LangGraph 状态图、节点连接、总时限与核验回路 |
| `nodes/` | 画像提取、内容规划、资源生成、格式整理节点 |
| `providers/` | 个人模型配置对应的四类协议适配器 |
| `prompts/` | 各角色提示词及版本记录 |
| `schemas/` | 节点输入输出、三类资源和核验结果结构 |
| `retrieval/` | 调用受权限约束的课程知识检索入口 |
| `validators/` | 结构、来源、课程事实规则及渲染安全核验 |

工作流方向为：输入与画像确认 → 课程知识检索 → 内容规划 → 资源生成 → 核验 → 格式整理与再次检查 → 后端事务保存。核验不通过时按约定有限重生成。后端负责认证、数据库事务、任务终态和资源所有权；智能体不自行决定用户身份或扩大检索权限。

模型协议预留为 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages、Gemini 原生协议。兼容服务通过相应协议与用户配置的 Base URL 接入。预留目录不代表任一协议已经通过真实服务验证；能力差异、错误格式和超时须分别测试。

当前不加载个人模型凭据、不发起外部模型请求、不执行用户或模型产生的代码。实现阶段的任务、交接与验收见根目录 plan.md。
