# 智能体模块边界

本目录已实现 LangGraph 工作流、四类文本协议、结构/来源核验、少量数据结构事实规则及权限限定向量检索。Python 环境由根目录 `pyproject.toml` 和 `uv.lock` 管理，后端在同一进程调用；发布成功资源仍由后端事务完成。

| 目录 | 职责 |
| --- | --- |
| `workflows/` | LangGraph 状态图、节点连接、总时限与核验回路 |
| `nodes/` | 画像提取、内容规划、资源生成、格式整理节点 |
| `providers/` | 个人模型配置对应的四类协议适配器 |
| `prompts/` | 各角色提示词及版本记录 |
| `schemas/` | 节点输入输出、三类资源和核验结果结构 |
| `retrieval/` | 调用受权限约束的课程知识检索入口 |
| `validators/` | 结构、来源、课程事实规则及渲染安全核验 |

工作流方向为：输入与画像确认 → 课程知识检索 → 内容规划 → 资源生成 → 核验 → 格式整理与再次检查 → 后端事务保存。核验不通过时按约定有限重生成。后端负责认证、数据库事务、任务终态和资源所有权；智能体不自行决定用户身份或扩大检索权限。

模型协议为 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages、Gemini 原生协议。兼容服务通过相应协议与用户配置的 Base URL 接入。四类协议已通过HTTP替身契约/错误测试，尚未获得真实服务配置，不能声称已通过真实服务验证。

生产调用由后端解密本人模型配置后注入适配器；本轮测试未发起真实付费模型请求。工作流没有执行用户或模型代码的工具。输入/材料按数据传入，模型判定与结构、来源规则共同检查。详情及限制见 `docs/design/implementation-v1.md` 和根目录 plan.md。
