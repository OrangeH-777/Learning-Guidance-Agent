# 公共课程知识

此目录只存放可供所有用户检索的公共课程资料。每门课程独立建目录，资料必须具有可核查来源和使用权限。当前 `data_structure/` 是空结构，不代表已导入教材或已建立索引。

```text
knowledge/
  data_structure/
    content/       # 经核对的知识正文
    sources/       # 资料来源、章节定位、使用限制与版本记录
  <course_id>/     # 后续确认课程后使用同样结构
    content/
    sources/
```

首期系统按多课程设计；实际课程清单、课程标识、来源记录格式和启用条件在 plan.md 的课程建设阶段确认。缺少可信材料或索引未就绪的课程不能被显示为可正常生成。

公共知识与私人材料必须分开：用户上传内容属于运行数据，保存在受控私有存储中，不能写入本目录、前端静态目录或版本仓库。私有存储的部署方式在上传功能设计时确认，配置入口预留为 `PRIVATE_UPLOAD_DIR`。

后续检索必须先确定已登录用户与所选课程，只允许访问该课程的公共条目及当前用户拥有的私有条目。来源详情、文件读取、片段预览、缓存及生成引用使用相同权限边界。目录名称和客户端提交的用户ID不能代替服务端授权。

部署方统一配置嵌入模型。索引记录模型、维度、资料版本与索引版本，切换嵌入模型须完成重建和验证；个人聊天模型的切换不改变嵌入配置。切块、排序、中文关键词方案及索引参数需评审后实施。
