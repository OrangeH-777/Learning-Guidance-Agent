# 栈与队列

栈采用后进先出：入栈和出栈作用于同一端。队列采用先进先出：从队尾加入，从队头移除。空栈出栈和空队列出队必须显式处理。固定容量循环队列须选定判满规则，例如牺牲一个槽位时，容量为 m 的数组最多存 m−1 个元素，空条件为 front=rear，满条件为 (rear+1) mod m=front。

# 栈与括号匹配：项目原创示例

从左至右扫描。左括号入栈；遇到右括号时，若栈空或栈顶类型不匹配则失败，否则弹出栈顶。扫描结束且栈空才成功。忽略非括号字符时要明确说明；仅验证括号序列时只接受六种括号字符。

示例：([]) 匹配，([)] 不匹配，(() 不匹配，空串匹配。对 n 个字符，每个最多入栈和出栈一次，时间 O(n)，最坏辅助空间 O(n)。仅统计左右括号数量无法保证嵌套正确。

## 示例教材：手工跟踪括号栈

本节为项目原创演示教材，尚待课程负责人审核。处理输入 ([)]：读到左圆括号后，栈内只有一个左圆括号；读到左方括号后，栈底到栈顶依次为左圆括号、左方括号。下一字符是右圆括号，但栈顶是左方括号，类型不匹配，立即失败，不继续用总数抵消。

下面的Python函数只接受六种括号字符；空串返回True，包含字母等其他字符时返回False。

```python
def brackets_match(text):
    stack = []
    matching = {')': '(', ']': '[', '}': '{'}
    for char in text:
        if char in '([{':
            stack.append(char)
        elif char in matching:
            if not stack or stack.pop() != matching[char]:
                return False
        else:
            return False
    return not stack
```

## 示例教材：循环队列

数组长度m=5，采用空出一个槽位的判满方案，初始front=rear=0。依次入队A、B、C、D后rear=4，(rear+1) mod 5=0，与front相同，因此已满，不能再放第五个元素。出队A后front=1，再入队E时写入下标4，rear回绕为0。队列逻辑顺序仍为B、C、D、E。

自测：上述循环队列最多存几个元素？答案是4个，因为长度5包含一个专门用于区分空和满的空槽位；如果改用计数器判满，应重新说明容量约定。
