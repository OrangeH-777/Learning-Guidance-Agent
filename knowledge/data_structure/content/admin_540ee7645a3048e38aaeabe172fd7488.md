# 排序算法的时间、空间与稳定性

稳定排序保留相等关键字元素的原相对次序，不能只根据最终数值序列判断稳定性。常见插入排序在近乎有序数据上表现较好，最坏时间 O(n²)；比较条件如何处理相等元素影响稳定性。

归并排序通常具有 O(n log n) 时间复杂度，数组版本需要 O(n) 辅助空间，合并相等关键字时优先取左侧可保持稳定。常见原地快速排序平均 O(n log n)，最坏 O(n²)，通常不稳定；递归栈空间必须计入。堆排序时间 O(n log n)，典型实现不稳定。

选型需同时考虑数据规模、初始顺序、稳定性、内存及最坏情况要求。任何复杂度结论都应注明算法版本和前提，不能用平均情况冒充最坏保证。

## 示例教材：直接插入排序

本节为项目原创演示教材，尚待课程负责人审核。每轮把当前位置的元素插入左侧已经有序的区间。下面的实现原地升序排序，返回同一个列表。

```python
def insertion_sort(values):
    for i in range(1, len(values)):
        key = values[i]
        j = i - 1
        while j >= 0 and values[j] > key:
            values[j + 1] = values[j]
            j -= 1
        values[j + 1] = key
    return values
```

对[5,2,4,1]，三轮结束后的序列依次为[2,5,4,1]、[2,4,5,1]、[1,2,4,5]。该实现只移动严格大于key的元素，相等元素不会互相越过，因而稳定；额外空间O(1)，已排序输入时间O(n)，逆序输入时间O(n²)。

## 示例教材：稳定性的观察方法

设两条记录(80,张同学)、(80,李同学)先后出现，按分数排序时，稳定排序保持张同学在李同学之前。只检查结果[80,80]无法发现次序改变，测试时要保留名字等身份标记。归并时相等优先取左侧，可保留原次序；普通快速排序交换元素时通常不能保证这一点。

## 自测与解析

问题：要求最坏O(n log n)且稳定，经典数组归并排序和普通快速排序哪个符合？经典稳定归并排序符合时间和稳定性要求，但通常需要O(n)辅助空间。普通快速排序既没有最坏O(n log n)保证，典型实现也不稳定。选择算法不能只比较平均时间。
