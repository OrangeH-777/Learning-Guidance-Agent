# 查找的前提和边界

顺序查找适合无序序列，最坏需要比较 n 个元素。二分查找需要按同一比较规则有序且可高效随机访问的序列；每次缩小约一半范围，比较次数 O(log n)。在普通链表上寻找中点的代价不能忽略。

闭区间实现采用 low≤high，命中则结束，未命中时排除已比较的中点；半开区间实现采用另一组一致的边界规则。空数组、首尾元素、目标不存在、重复元素都应测试，存在重复值时应明确返回任意位置还是最左/最右位置。

二叉搜索树按键有序，查找成本与树高有关。树平衡时可达 O(log n)，退化为链时最坏 O(n)。不能将普通二叉树与二叉搜索树混为一谈。

## 示例教材：寻找最左匹配位置

本节为项目原创演示教材，尚待课程负责人审核。下面使用半开区间[low, high)，要求输入按升序排列，并返回目标第一次出现的位置，不存在时返回−1。

```python
def binary_search_first(values, target):
    low, high = 0, len(values)
    while low < high:
        mid = low + (high - low) // 2
        if values[mid] < target:
            low = mid + 1
        else:
            high = mid
    if low < len(values) and values[low] == target:
        return low
    return -1
```

对于[2,4,4,7,9]查找4：第一次mid=2，虽然命中4，仍把high缩为2，继续向左；随后mid=1，high变为1；最后mid=0，low变为1，循环结束，返回1。若遇到相等就立即返回，只能保证得到一个匹配位置，不能保证最左。

## 自测与解析

空数组查找1返回−1；[4]查找4返回0；[2,4,4,7,9]查找8返回−1；同一数组查找9返回4。实际实现要先验证low没有越界再读取values[low]。循环每步缩小候选范围，因此数组上的时间O(log n)、额外空间O(1)，不含对输入排序的成本。
